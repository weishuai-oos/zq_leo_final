- Python 3.11，Torch 2.7，CusRL 1.1.8.post0，IsaacLab 2.3.2 / Isaac Sim 5.1。
- 当前会话没有可用 CUDA GPU；物理冒烟和小规模更新使用真实 IsaacLab CPU 后端。

- Pyright 项目声明范围为 0 errors / 0 warnings；另检查了纯 Torch 击打、头部屏蔽和续训辅助模块。

## 头部隔离与导出

单元测试覆盖头部反馈 NaN/Inf、头槽占位、AMP 两侧一致性、被动/弱驱动和无头映射。
真实检查点的优化 JIT 连续 5 步与原网络比较，最大误差为 `4.768e-7`；
注入头部异常输入后输出仍与对应健康占位输入一致，两个头动作槽位为零。
ONNX 已完成实际导出和完整结构检查；当前环境缺少 ONNX Runtime，未做 ONNX 数值推理对比。
部署契约保留原逻辑关节顺序、实际 scale/default offset，并说明循环状态的重置要求。

## 验证边界

尚未执行 GPU 多卡物理训练、长期收敛评估、完整回合或实机抗击打测试。
CPU 后端启动/关闭时仍会报告缺少合适 CUDA GPU，另有原资产手腕可视网格及 SDK 弃用告警；
它们没有阻止上述 CPU 步进、更新和最终恢复进程正常结束，不能因此推断 GPU 后端已通过。

当前外力模型不模拟真实拳脚阻挡、勾挂、绊腿；没有物理围笼和软垫压缩模型。
头部驱动失能、头部反馈隔离和无头验证已实现，电线悬挂及结构断裂未建模。
柱状障碍与地面共用网格，身体触柱保守判倒地；足底区域使用平均接触点近似。
这些边界以及工况参数和启动命令见 [抗击打续训说明](抗击打续训说明.md)。
