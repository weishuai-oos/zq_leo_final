# T800 单任务工程抽取计划

原工程：../zq_leo，基准提交 75c84ce；仅在 zq_leo_final 写入。

## 验收条件
- 独立包 t800_lab，训练任务 T800_base，评估任务 T800_base-Play；不注册其他机器人或实验变体。
- 展开 LowCylinders-MN-StdTarget-Plus-AnkleStable-1 的有效配置，只保留必要配置分组和一个 Play 子类，删除旧任务多层继承。
- 除用户要求的地形变化外，保留动作/观测顺序、标准姿态目标、AMP、奖励、物理和命令采样语义。
- 地形列数采用50：flat20%、perlin8%、rough12%、wave12%、boxes8%、horizontal40%，对应10/4/6/6/4/20列；十行难度。
- 复制 T800 资产与实际使用的 AMP 数据，项目运行不能依赖原 leo_lab 包或原工程文件。
- 保留训练、恢复、Play、诊断及导出所需入口；不搬训练日志、旧 checkpoint、G1/击打任务或无关工具。
- 默认从零训练；不加入未经用户要求的阶段切换、奖励渐增或额外奖励。记录和解释从零训练与历史续训差异。
- 独立文档记录任务来源、最终配置、历史恢复链，以及后续 AnkleStable-1-Plus 的奖励差异（不启用该变体）。

## 顺序及行为保护
1. 运行原有脚踝/命令/AMP 相关 CPU 回归，建立基线。
2. 先建立新工程契约与独立配置对照验证，再抽取运行时依赖并展开最终配置。
3. 并行任务按文件分工：配置实现、测试与原配置对照、运行时/入口/文档。
4. 验证新旧配置除地形/任务命名之外的一致性；检查所有本地依赖、数据和 URDF 网格引用闭合。
5. 执行 CPU 回归、静态检查、编译、安装元数据检查及可行的仿真冒烟；任何无法执行的验证据实记录。

## 精简边界
删除无关任务和旧版本继承；通用库只按 T800 实际依赖抽取，不新增第三方依赖。保留 IsaacLab/CusRL 版本边界的有据兼容行为，不引入吞错或静默替代路径。原工程不作修改。
