# T800_base 的来源与最终配置

本文记录 `T800_base` 的任务来源、原任务的有效配置和可核实的续训链。新工程采用的基线是：

```text
LeoLab-Locomotion-T800-AMP-Terrain-LowCylinders-MN-StdTarget-Plus-AnkleStable-1
```

原环境类为 `T800LowCylinderTerrainAmpMaskBaseNarrowStdTargetPlusAnkleStable1EnvCfg`。新任务将历史覆盖结果直接写入一个环境配置，不再保留用于试验对照的多层任务继承。除增加 20% 纯平地及相应调整列数外，训练行为以该最终任务为准。

重建时参照原工程 `/srv/shared/home/xjh/workspace/zq_leo` 的提交 `75c84ceb8416f56316b961300b018d733a8f6605`（2026-09-09，提交说明“修改脚抖问题”）。训练 run 的 `info/workspace/version.txt` 为 `unknown`，另有工作树快照；因此此提交是此次代码重建的参照，不代表每次历史训练都在完全相同的干净提交上运行。

## 1. 最终任务具体选了哪些配置

| 名称部分 | 最终采用的内容 |
|---|---|
| `T800-AMP` | 仅 T800，25 个关节输出位置目标；PPO 任务奖励叠加 AMP 风格奖励。 |
| `Terrain-LowCylinders` | 低矮障碍混合地形；障碍包括圆柱、六棱柱和箱体，名称并不表示只有圆柱。 |
| `M` | `MaskBase`：AMP 判别器去掉独立的基座线速度、角速度项；保留指令条件、重力方向、关节位置和速度。Actor/critic 自身的基座观测仍存在。 |
| `N` | `Narrow`：拳击移动的窄范围命令分布；最终 `Plus` 又将纯转向范围改成 1.00–2.10 rad/s。 |
| `StdTarget` | 用“标准姿势”NPZ 的手臂/头部角度作为额外姿态奖励目标；动作零位仍是拳击 guard nominal pose。选用的是 `use_standard_action_offset=False`，不是 `StdOffset-Target` 对照。 |
| 第一个 `Plus` | LowCylinders 地形改为每列固定一个地形家族、每行增加难度；20 列精确表达原比例；恢复系数随机化扩大到 0–0.4；纯转向减为 1.00–2.10 rad/s；增加课程地形统计。 |
| `AnkleStable` | 在原奖励上增加 6 个独立踝关节奖励，并在 reset 时清空差分历史。 |
| `1` | 踝稳定最低强度组：目标速度 -0.010、目标加速度 -0.0020、实际超速 -0.025、实际加速度 -0.001；两个软限位项各 -0.20。它是奖励级别，不是 checkpoint 编号。 |

这里的 `Plus-AnkleStable-1` 与后续的 `Plus-AnkleStable-1-Plus` 是两个任务。后者另外增加 4 个边界奖励，见 [后续Plus版本改进说明.md](后续Plus版本改进说明.md)，本工程不包含该变体。

### 命令采样

命令每 4–6 s 重新采样，采用相对 root-yaw 方向偏转 **+37°** 的战术前向坐标系采样平面方向，再转回训练奖励使用的 root-yaw 坐标系。没有 heading 跟踪控制。

| 模式 | 概率 | 范围 |
|---|---:|---|
| 站立 | 10% | 全零命令 |
| 战术前/后/左/右平移 | 50% | 速度模长 0.65–1.10 m/s，四方向均匀 |
| 原地转向 | 20% | 角速度模长 1.00–2.10 rad/s，正负均匀 |
| 其他平移 | 15% | 四个斜向，方向抖动 ±15°，速度 0.80–1.35 m/s |
| 平移与转向混合 | 5% | 任意平面方向，速度 0.80–1.25 m/s，角速度模长 0.50–1.80 rad/s |

配置中的 `ranges` 为 `vx,vy∈[-1.35,1.35]`、`wz∈[-2.10,2.10]`；实际采样由上述模式控制，不能将其理解为每个分量独立均匀采样。

### PPO 与 AMP 算法

Actor、critic 都是 2 层 LSTM、hidden size 256；高斯动作分布。每次 update 收集 24 步，5 个 epoch、4 个 mini-batch；AdamW 初始配置学习率 0.001。采用 observation normalization、GAE（γ=0.99、λ=0.95）、advantage normalization、value loss 权重 0.5、PPO clip=0.2、entropy=0.003、梯度范数裁剪 1.0，目标 KL=0.015 的自适应学习率。

AMP 判别器 MLP 为 512/256，batch=512，loss weight=1，gradient penalty=5。保留原项目的 `ScaledAdversarialMotionPrior`，使风格奖励真正乘上 **0.03**。去掉这层后简单替换成 upstream hook 可能改变有效奖励比例。原默认 `max_iterations=50000`、`save_interval=1000`；历史命令覆盖了训练终点，这些终点是绝对迭代号，不是新增迭代数。

结构与算法参数同时由原 run 的 `info/agent_info.txt` 验证：actor 84→LSTM、critic 87→LSTM、action_dim=25、AMP_dim=96、每 rank 1024 环境。

## 2. 地形：原分布和新工程的明确改动

原 `LowCylinders-...-Plus` 并非“低难度几行平地、高难度几行全是圆柱”的旧 `fallen_robot_progression`。它是 **同一列始终保留同类地形，沿行增加该类难度**，适合无高度扫描的盲走策略。

| 地形家族 | 原比例 / 20 列 | 新比例 / 50 列 | 主要几何配置 |
|---|---:|---:|---|
| 纯平地 `fight_mat_flat` | 0% / 0 | 20% / 10 | 标准 MeshPlane |
| Perlin | 10% / 2 | 8% / 4 | noise range 0–0.012 m |
| 平滑随机粗糙地 | 15% / 3 | 12% / 6 | height range -0.012–0.030 m |
| 波浪地 | 15% / 3 | 12% / 6 | amplitude range 0–0.08 m，wave_count=5 |
| 稀疏低箱体 | 10% / 2 | 8% / 4 | count range 4–18，height 0.015–0.08 m，footprint 0.25–0.50 m |
| 水平障碍 | 50% / 10 | 40% / 20 | count range 0–20，露出高度 0.03–0.12 m、mode=0.10 m |

新比例严格由 `原比例×0.8` 得到，并加入 0.2 平地；采用 **10 行×50 列**，因此列数精确为 **10/4/6/6/4/20**，没有舍入后吞掉小类别的问题。原地形 10×20，新地形 10×50；单块仍 8×8 m，border=20 m，horizontal/vertical scale=0.05/0.002，seed=43，difficulty range=0–1，use_cache=False。

水平障碍形状权重为圆柱/六棱柱/箱体=0.65/0.20/0.15；长度 0.80–1.20 m；圆柱/六棱柱半径 0.12–0.22 m，箱宽 0.20–0.38 m；spawn clearance=1 m。表中范围是配置范围，生成器按难度调节实际振幅、数量与高度，不表示每一行都会覆盖整个范围。初始地形最高 level=1，之后按回合实际位移和命令要求的位移升/降级；保留各地形课程统计。

## 3. 可核实的历史续训过程

**Python 类继承与 checkpoint 继承是两件事。** 原环境类经过 flat→tuned→AMP→terrain→AnkleStable 的配置继承，只决定最终参数。只有训练命令明确出现 `--checkpoint` 才能证明从某个权重和训练状态继续。不能因为任务继承了另一个类，就认为其历史权重也按同一路径训练过。

下列 run 均位于原工程 `logs/cusrl/t800_base_amp/`，日期均为 2026 年。

| 起始时间 / run | 已证实的加载点 | 实际保存 / 使用节点 | 说明 |
|---|---|---|---|
| 08-27 15:00:33 `t800_amp_terrain_mild_mn_std_target_plus_2gpu_seed42` | 无 checkpoint，从零开始 | 被下阶段选择的是 `ckpt_44000.pt`；目录还保留到 52000 | `9027_0.out` 明确记载 2 GPU、全局 4096、checkpoint none；命令目标 60000 不代表实际达到了 60000。 |
| 08-30 18:42:56 `t800_amp_terrain_lowcylinders_mn_std_target_plus_resume_2gpu_seed42` | 上一 Mild-Plus run 的 44000 | 被踝稳定续训选择的是 `ckpt_93000.pt`；目录还保留到 96000 | 切换到 LowCylinders-Plus 地形，2 GPU，全局 4096；命令目标 104000。 |
| 09-06 19:30:18 `t800_lowcylinders_ankle_stable_1_seed42` | 上一 LowCylinders-Plus run 的 93000 | **109000 是后续 Plus 选用的基线节点；该 run 最终实际保存到了 133000** | 4 GPU，全局 4096，增加 40000 updates；不能将 109000 误写成这次训练的最终停止点。 |

## 4. 新工程如何一步从零训练

`T800_base` 从初始化就启用最终级别 1 的六项踝奖励，使用表中的完整权重、完整 AMP 和新的 20% 平地混合地形。启动新训练不传 `--checkpoint`，不使用 `--finetune_lr_scale`、`--finetune_origin_iteration` 或 `--finetune_warmup_iterations`。初始学习率仍来自算法配置的 0.001，由 AdaptiveLRSchedule 正常调整，不继承旧 run 的约 2e-5 学习率上限。

历史 LR 下调和奖励 warmup 是为保护已经训练出的步态而设计的续训机制；新网络从零开始没有必须保护的旧策略，不需要重复 44000→93000 的人为分阶段加载。这表示训练过程可以单次启动到目标迭代，不表示其随机优化结果必然与旧 checkpoint 完全相同。自动地形课程仍保留，属于这一个任务内部的训练机制。
