一次运行一组。以上命令使用单环境、固定平地、相同 seed 42、键盘控制，不录视频或原始诊断数据。终端 Ctrl+C 退出后再切换下一组。

机器人键盘操作：按住方向键前后/侧移，松开停止；`C` 循环切换速度档，默认第一档；`Z` / `X` 转向，`L` 清零速度指令。先点一下仿真窗口再操作。

想看其他地形，可将命令中的地形参数替换为 `--terrain_level 3 --terrain_type fight_mat_horizontal_obstacles`。

## 镜头

`--free_camera` 现在会在启动重置后的第一帧，按所选机器人实际世界坐标定位镜头；默认选环境 0，镜头距机器人约 3 米。之后可自由移动，走路和 episode 重置不会重新对准。去掉此参数仍可使用原来的跟随模式。

多环境时可指定启动位置，例如 `--num_envs 4 --camera_env 2`；环境编号从 0 开始。只做启动定位，没有新增持续跟随。
