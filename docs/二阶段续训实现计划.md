# T800_base-Impact 实现与验证计划

本阶段继承 T800_base 的 LSTM PPO / AMP 检查点，训练受击后保持或恢复稳定。
弱击不要求迈步，稳定优先于恢复速度和额外位移。第一阶段任务保持独立。

## 已确定的契约

- Actor / Critic / Action / AMP 维度维持 84 / 87 / 25 / 96，保留关节、观测、参数及 hook 顺序。
- 头部位置、速度、历史动作和 AMP 对应通道保留占位；训练与导出使用一致的屏蔽规则。
- 头部由固定姿态控制接管，采样失能、弱化等物理状态；无效头部数据不能进入归一化或 LSTM。
- 地形为 80% 平地、20% 水平柱状障碍。来袭方位为正面/斜前 60%、侧面 35%、背面 5%。
- 初始样本比例为无击打 25%、常见受击 65%、压力场景 10%；极端场景随课程逐步开启。
- 常见力峰覆盖几十至 2000 N，压力上限 5000 N。脉宽、冲量与部位共同约束；默认范围为待标定工程参数。
- 外力按 5 ms 物理步执行，使用有限时长脉冲、实际受击刚体与偏心作用点，结束/reset 清理。
- 新任务必须显式提供 checkpoint；恢复后校验完整状态，再设置学习率上限。
- 保存阶段起点、课程进度、学习率上限和参数版本，第二阶段恢复不重置课程或再次减半学习率。

## 实施分工与文件

1. 新增 `tasks/t800_impact/impact_config.py`、`impact_runtime.py`，实现采样、脉冲、物理步施力、恢复状态及指标。
2. 新增 `tasks/t800_impact/head_mdp.py`、`actions.py`，实现头部隔离、固定头目标和物理故障，保留逻辑尺寸。
3. 新增严格恢复和阶段状态辅助，扩展 train/play/export 入口及独立 Slurm 续训入口。
4. 新增第二阶段环境、地形、奖励、注册与诊断；不修改 T800_base 的训练行为。
5. 增加行为测试：离散冲量、坐标系/力矩、reset、无击打、方向采样、课程恢复、头数据异常、checkpoint 严格恢复。
6. CPU 回归、Ruff、Pyright 声明范围、编译检查、真实 Isaac 配置检查；执行 CPU 物理冒烟和小规模更新，GPU 多卡另验。

## 验收和限制

先证明程序、配置、恢复与数值接口正确，再通过固定工况评估倒地率、恢复时间及额外位移。
CPU 测试不能证明抗击打效果；短物理冒烟不能证明训练收敛。
外力注入不等同于真实拳脚碰撞、绊碰、主动格挡或结构断裂。
头部被动摆动和缺失头部验证分别记录；悬挂头部的简化模型不冒充真实电线断裂仿真。
围笼和比赛接触判定按实现与实测验证范围明确记录，不以碰撞合力混同对手受击与触地倒地。
